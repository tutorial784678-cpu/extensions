Help and deployment notes

Important limitations of this frontend-only local demo.

Demo authentication only. The administrator password is present in this frontend source code. It provides no real production security and must not be treated as a secure authentication system.
Browsers may restrict IndexedDB or file behavior when these files are opened directly using file://. Use a local server during development:

python -m http.server 8000

Then visit http://localhost:8000/index.html and http://localhost:8000/admin.html.

Never inject ZIP contents into the page, evaluate uploaded code, execute JavaScript from the ZIP, or render extracted files as HTML. This application does not unpack or execute the uploaded ZIP.

Local demo disclaimer: This frontend-only admin portal stores data locally in IndexedDB.

No password, ZIP, token, or credential is stored in IndexedDB.
