Chrome installation instructions

A website cannot directly install or enable a Chrome Extension because of browser security restrictions. Install the downloaded package manually:

  1. Download the extension ZIP file.
  2. Extract the ZIP file into a folder.
  3. Open Chrome.
  4. Navigate to chrome://extensions.
  5. Enable Developer mode.
  6. Click Load unpacked.
  7. Select the extracted extension folder.
  8. Confirm that the extension appears in Chrome.
  9. Pin or enable the extension if required.
Important: The extracted folder must contain manifest.json at its root and the extension must use a valid Chrome Extension Manifest. Chrome may block or reject extensions with invalid manifests, missing permissions, or unsupported APIs. Never bypass Chrome security warnings.
Security warning: Only install Chrome Extensions from a trusted source. Review the requested permissions before installing.

Local-only storage notice

The ZIP is stored as a Blob in this browser’s IndexedDB. It is not uploaded to a server, and other devices will not automatically see it. Clearing browser site data may delete the extension.

A production distribution portal requires a backend service and persistent file storage.

Browsers may restrict IndexedDB or file behavior when these HTML files are opened directly with file://. For local development, run:

python -m http.server 8000

Then open http://localhost:8000/index.html and http://localhost:8000/admin.html.

Local demo disclaimer: This portal is frontend-only and stores extension data locally in the current browser.

Downloading a ZIP does not automatically install or enable the Chrome Extension.
